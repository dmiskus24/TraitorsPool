Add one JPG headshot per contestant in this folder.

File names should use the contestant's slugged name, for example:
- abbey-benjamin.jpg
- abby-lee.jpg
- arisa-thomas.jpg
- ben-mcdonnell.jpg
...

When these files are present, the app will automatically show the photo on contestant cards, leaderboard pills, and the profile modal.
If a photo is missing, the app falls back to initials.
